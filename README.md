# cc-fisheries

管理捕捞配额、权属变化和卸港申报。

## 主要业务规则

### 配额账户

- 账户按 **捕捞季 + 物种 + 权利人** 组合唯一管理（数据库唯一约束），开立时核准入账。
- 所有数量使用固定精度 `BigDecimal`（3 位小数），超精度输入直接拒绝。
- 账户分别维护三个余额：**可用（available）**、**冻结（frozen）**、**已核销（consumed）**；
  任何操作后 `可用 + 冻结 + 已核销` 守恒，且任何余额不得为负。
- 账户带 JPA 乐观版本号，任何余额变化都会推进版本；复核、更正等“决定”在创建时记录
  所基于的账户版本，执行时版本已变化即拒绝旧决定。

### 配额转让

- 转让方发起转让时，从其可用量中冻结相应数量（可用不足则拒绝）。
- 受让方接受后，在**同一事务**内扣减转让方冻结量、增加受让方可用量；
  受让方必须在同一捕捞季/物种下持有账户，因此转让不能跨捕捞季或物种。
- 受让方拒绝或转让到期时，冻结量**只释放一次**（状态机 `PENDING → ACCEPTED/REJECTED/EXPIRED`，
  已终结的转让不能再次变更）；到期释放由定时任务或 `POST /api/transfers/expire-due` 触发，
  在独立事务中提交。

### 卸港申报与港口复核

- 申报包含唯一事件号、渔船、权利人、物种、捕捞季和重量。申报**先冻结**权利人可用配额并进入
  `PENDING_REVIEW`（待复核），此时只冻结、不核销。
- 港口复核人提交复核事件（复核事件号全局唯一，同一申报只能复核一次）：
  - **确认**：确认重量等于申报重量时冻结量直接转为已核销；小于申报重量时按确认量核销、
    差额冻结归还可用量；大于申报重量时申报量由冻结核销、增重差额从可用量追扣，
    可用不足则整个复核失败（不写任何台账）。
  - **拒绝**：冻结量全额释放回可用量，申报进入 `REJECTED`。
- 冻结、确认、释放都在申报行锁 + 账户悲观行锁内完成，三量守恒且任何时刻不为负。
- 申报事件号与复核事件号均幂等：相同内容重放返回原记录，内容不同返回 `409 Conflict`；
  并发下由数据库唯一约束兜底。

### 称重更正与配额差额

- 只有**已核销（CONFIRMED）**的申报才能更正。更正引用原申报，原申报重量与原台账**永不覆盖**，
  生效重量（`confirmedWeight`）随每次成功决定推进，申报版本号同步自增。
- 创建更正时记录所基于的**申报版本**与**账户版本**，此时尚不发生任何配额变化；
  更正确认时在单事务内重新校验两个版本，任一已变化即拒绝旧决定（`409`），
  需基于最新版本重新发起。
- 确认时按**实际差额**处理配额：增重从可用量追扣差额（不足则整个确认失败回滚，
  不写入部分差额台账）；减重只把实际差额从已核销归还到可用量。
- 更正号幂等：重复创建返回原更正，重复确认直接返回，不重复扣减或归还。

### 并发与台账

- 所有余额变更先取账户行的**悲观写锁**（`SELECT ... FOR UPDATE`），申报/转让/更正单的状态迁移
  持有各自行锁；加锁顺序固定（申报行 → 账户行；双向转让按权利人排序），避免死锁。
- 账户与申报另有 JPA 乐观版本号兜底：转让接受、卸港确认、更正确认并发时，
  任何时刻账户不得为负，旧版本决定被拒绝。
- 每次余额变化写入一条**不可变台账事件**（含变化后三余额快照及关联单号）；
  失败请求事务回滚，不写入台账，也不写入部分差额。

### 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/quota-accounts` | 开立账户并核准入账 |
| GET | `/api/quota-accounts`、`/api/quota-accounts/{id}` | 账户查询（含版本号） |
| GET | `/api/quota-accounts/{id}/ledger` | 账户差额台账（三余额快照） |
| GET | `/api/quota-accounts/{id}/freezes` | 冻结明细（待接受转让 + 待复核申报） |
| POST | `/api/transfers` | 发起转让（冻结） |
| POST | `/api/transfers/{id}/accept`、`/reject` | 接受 / 拒绝 |
| POST | `/api/transfers/expire-due` | 处理到期转让 |
| GET | `/api/transfers/{id}`、`/api/transfers` | 转让查询 |
| POST | `/api/landings` | 卸港申报（冻结并进入待复核，幂等） |
| POST | `/api/landings/{eventId}/reviews/confirm` | 复核确认重量（复核事件号幂等） |
| POST | `/api/landings/{eventId}/reviews/reject` | 复核拒绝（释放冻结） |
| POST | `/api/landings/{eventId}/corrections` | 创建称重更正（更正号幂等） |
| POST | `/api/landings/corrections/{correctionNo}/confirm` | 确认更正（版本校验 + 差额处理） |
| GET | `/api/landings/{eventId}/versions` | 申报版本链（原申报 + 复核 + 更正链） |
| GET | `/api/landings/{eventId}`、`/api/landings` | 卸港记录查询 |

### 台账事件类型

| 类型 | 含义 |
| --- | --- |
| `GRANT` | 账户核准入账 |
| `TRANSFER_FREEZE` / `TRANSFER_RELEASE` / `TRANSFER_OUT` / `TRANSFER_IN` | 转让冻结 / 释放 / 转出 / 转入 |
| `LANDING_FREEZE` | 卸港申报冻结可用配额 |
| `LANDING_SETTLE` | 复核确认，冻结量（或确认量）正式核销 |
| `LANDING_RELEASE` | 复核拒绝或确认量小于申报量时释放冻结 |
| `REVIEW_CONSUME` | 复核确认重量大于申报量，从可用量追扣增重差额 |
| `CORRECTION_DEDUCT` | 更正增重，从可用量追扣差额 |
| `CORRECTION_RETURN` | 更正减重，实际差额从已核销归还可用量 |
